Embed ogham

Put scalable, drawn ogham on your own page with one script tag. No build, no font.

Add it

<script src="https://ogham.doyled-it.com/embed/ogham.js"></script>

<ogham-text text="meitheal"></ogham-text>

That registers the <ogham-text> element and a window.Ogham.oghamSVG(text, options) function. The drawing scales to its container; add the physical attribute to keep millimetre sizing for print or a laser cutter.

Attributes

AttributeValues
textthe text to draw
modelatin (default) or unicode (draw pasted ogham code points)
orientationvertical (default) or horizontal
traditionmanuscript (default) or monumental
colourwaycarved, bronze, orpiment, redlead, woad, verdigris, crotal, irongall
wordsgap (default), per-word, none
featherstart (default), both, none
weightthin, regular (default), heavy
spacingstroke spacing in mm (default 5)
backgroundtransparent (default), white, canvas
physicalpresent to keep millimetre sizing instead of scaling to the container

Examples

From code

const { svg } = Ogham.oghamSVG('meitheal', { orientation: 'horizontal', colourway: 'woad' });
document.querySelector('#here').innerHTML = svg;
